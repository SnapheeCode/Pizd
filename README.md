# Avtor24 Autobidder MVP

Этот проект реализует минимально жизнеспособную версию бота для площадки Автор24. Бот построен на полученных из HAR-файла GraphQL запросах и поддерживает требования из ТЗ: приоритизация новых заказов, фильтрация, шаблонные сообщения и отложенные догоняющие письма.

## Возможности
- Асинхронный сбор заказов с GraphQL API и поддержание приоритетной очереди.
- Настраиваемые фильтры по типам и предметам для каждого аккаунта.
- Ограничение частоты ставок и планирование отложенных сообщений.
- Сохранение конфигурации и состояния между запусками в JSON-файлах.
- Многопоточность за счёт запуска отдельного воркера на аккаунт.

## Быстрый старт
```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
avtor24-bot run ./configs
```

Подробности по настройке находятся в `docs/USAGE.md`.
